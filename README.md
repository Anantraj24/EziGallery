# Ezi Gallery 📸

A modern, fast, and lightweight Android gallery app designed for seamless photo and video viewing, organization, and management.

## 🌟 Overview

**Ezi Gallery** provides a clean and responsive media gallery experience for Android devices with smooth performance and a privacy-first approach.

## 🚀 Getting Started

### Prerequisites

- Android Studio Iguana / Ladybug or newer
- Android SDK (API 34+)
- JDK 17 or higher

### Installation & Build

1. Clone the repository:
   ```bash
   git clone https://github.com/Anantraj24/EziGallery.git
   ```
2. Open the project in **Android Studio**.
3. Allow Gradle to sync dependencies.
4. Run on an Android emulator or physical device.
