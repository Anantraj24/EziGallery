# Luma Gallery — Phase 1

Luma is an offline-first Android gallery designed to be fast on low-end phones.

## Phase 1 scope
Photos, albums/folders, viewer, video playback, favorites, search, selection, share, delete, themes, and basic settings.

## Explicitly deferred
Editor, vault, AI, duplicates, storage cleaner, maps, cloud backup, PC transfer, memories, advanced metadata tools.

## Start with Antigravity
Read `AGENTS.md` and `ANTIGRAVITY_PROMPT.md`, then follow `tasks/PHASE_1_ROADMAP.md` one milestone at a time.

Do not implement the whole roadmap in one pass.
