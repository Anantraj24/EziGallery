# Phase 1 Roadmap

## Milestone 0 — Project foundation
- Verify Gradle/SDK
- Establish package structure
- Establish theme
- Establish navigation
- Add baseline error handling

- Permission flow
- MediaStore repository
- Photo/video model

## Milestone 2 — Photos
- Date-grouped grid
- Lazy thumbnail loading
- Sorting
- Responsive columns
- Viewer

## Milestone 3 — Albums
- Folder/collection list
- Album detail
- Navigation back to grid

## Milestone 4 — User actions
- Favorites
- Selection mode
- Share
- Delete confirmation

## Milestone 5 — Search
- Filename/display-name search
- Result grid
- Empty state

## Milestone 6 — Settings
- Theme
- Grid density
- Sort preference
- Group-by-date preference
- About/version

## Milestone 7 — Performance and QA
- Low-RAM testing
- Large-library testing
- Rotation/configuration testing
- Permission denial testing
- Crash review
- Build/release verification

Do not begin Phase 2 until Phase 1 Definition of Done is satisfied.
